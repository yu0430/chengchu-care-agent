# 澄初个人护理智能导购

这是题目 08 的可现场试用 Agent。用户用自然语言描述肤质、护理目标、香味偏好、预算或政策问题，系统依据题目提供的虚构品牌资料进行追问、商品选择、价格核算和安全边界处理。

## 支持的输入

- 商品和价格查询，例如“P101 多少钱”
- 指定品类选择，例如“偏油，想买洁面”
- 完整护理需求，例如“偏油，喜欢清爽，推荐一套”
- 敏感、不适、受损、持续或反复问题
- 预算金额、预算不限或暂不提供预算
- 香味偏好、硬性无香要求和香味敏感情况
- 促销、赠品、线上同价、退换货和渠道授权问题

## 决策流程

```text
用户输入
  → 提取明确事实并保留原话
  → 确定性决策规划
      ├─ 缺少关键信息：每轮追问 1 至 2 项
      ├─ 安全边界：停止相关护肤推荐并提示咨询专业人士
      ├─ 政策问题：按品牌资料回答或提示向门店/系统确认
      └─ 条件完整：生成候选
  → 校验适用条件和限制
  → 独立计算商品价格与预算关系
  → 输出建议、理由、价格和提醒
```

商品事实来自 `data/products.json`，品牌原则、组合与政策边界来自 `data/policies.json`。大模型负责理解自然语言和普通对话；推荐路线、缺失信息、候选商品、安全拦截和预算结论由确定性程序决定。

系统区分以下结果：

- 仍需确认：正常追问，不进入商品校验
- 可以建议：适用条件和预算均已核对
- 可以建议但需提醒：必须同时展示重要限制
- 非首选：说明原因，不表述成绝对禁用
- 预算冲突：给出总价和差额，不自动替换成不适用商品
- 安全阻断：停止相关护肤推荐
- 资料未覆盖：明确说明无法判断或需要门店、系统、人工确认
- 系统错误：内部候选或报价失败，不要求用户重新描述需求

## 安装与启动

建议使用 Python 3.12。

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

复制 `.env.example` 为 `.env`，配置：

```env
DASHSCOPE_API_KEY=your_dashscope_api_key_here
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_CHAT_MODEL=qwen3.6-flash
```

启动现场演示页面：

```powershell
python -m streamlit run app.py
```

## 输出内容

正式建议包含：

1. 已确认需求
2. 推荐商品和 SKU
3. 推荐理由
4. 单价、数量、总价和预算关系
5. 使用提醒与限制
6. 仍需确认的信息

页面折叠区展示用户原话证据、品牌规则来源、价格核算和允许输出的结论。顾客正文不会展示内部工具名、状态码、规则编号或考试资料文件名。

## 自测样例

输入：

```text
偏油清爽，推荐什么？
```

预期第一轮：

```text
确认整体预算和香味偏好，不提交商品校验。
```

继续输入：

```text
400
可以接受香味
一起，对香味不敏感
```

预期结果：核对 P102 与 P203，单价分别为 149 元和 219 元，总价 368 元，在 400 元预算内，并保留两件商品的香味限制。

预算冲突样例：

```text
请搭配一套。我偏干、有敏感倾向，希望简单护理，预算 400 元。
```

预期结果：资料组合 P101 与 P202 总价 428 元，超过预算 28 元；系统询问是否调整预算或优先选择一个品类，不自动替换商品。

政策边界样例：

```text
网上价格更便宜吗？有赠品吗？
```

预期结果：品牌资料没有提供线上同价和赠品政策，需要向门店或系统确认。

## 测试

```powershell
python -m unittest discover -s tests -v
```

`tests/test_decision_flow.py` 覆盖整段多轮流程，包括逐项回答、硬性无香、预算不限、持续问题、安全停止和政策路径。其余测试覆盖商品查询、组合校验、报价、需求证据和页面文案。
